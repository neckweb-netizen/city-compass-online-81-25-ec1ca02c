# Saj Tem

Aplicação React + TypeScript do guia local Saj Tem, com Vite, Supabase e funções de servidor.

## Desenvolvimento

Requer Node.js 20.19 ou mais recente (até a versão 24).

```bash
npm install
npm run dev
```

## Validação

```bash
npm run typecheck
npm run lint
npm run build
npm audit
```

Antes de publicar as correções de segurança, siga o checklist em [docs/SECURITY_DEPLOYMENT.md](docs/SECURITY_DEPLOYMENT.md).
